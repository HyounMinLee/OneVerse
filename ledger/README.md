# 월 지출 (가계부)

성경 구절 앱과 같은 GitHub 저장소·같은 토큰을 사용하는 월별 지출 관리 페이지입니다.
입력한 내용은 저장소에 월별 JSON 파일로 커밋됩니다.

## 구성

```
(저장소 루트)
├─ index.html          성경 구절 앱 (기존)
├─ .nojekyll           (기존)
├─ data/               성경 구절 데이터 (기존)
└─ ledger/
   ├─ index.html       가계부 화면 (HTML/CSS/JS 단일 파일)
   ├─ README.md
   └─ data/            가계부 데이터 (첫 저장 시 자동 생성)
      └─ 2026/
         └─ 2026-10.json
```

접속 주소: `https://<아이디>.github.io/<저장소이름>/ledger/`

## 올리는 방법

1. 저장소 루트에 `ledger` 폴더를 그대로 올립니다. (GitHub 웹: Add file → Upload files → `ledger` 폴더를 끌어다 놓기)
2. Commit changes를 누릅니다.
3. 1~2분 뒤 위 주소로 접속합니다.

## 연결 정보

- 같은 `github.io` 주소에서 성경 구절 앱에 토큰을 저장해 둔 기기라면 **추가 설정 없이** 그 소유자·저장소·브랜치·토큰을 그대로 사용합니다.
  - 브라우저 저장 키 `dailyVerse.github`를 읽습니다. 성경 앱에서 토큰을 바꾸면 가계부도 함께 바뀝니다.
- 가계부만 다른 토큰을 쓰려면 오른쪽 위 연결 아이콘에서 새 토큰을 입력합니다. (저장 키 `ledger.github`)
- 데이터 폴더 기본값은 `ledger/data`입니다.

## 월 파일 형식

```json
{
  "month": "2026-10",
  "salary": 4500000,
  "columns": [
    { "id": "c1", "name": "기업 1" },
    { "id": "c2", "name": "기업 2" },
    { "id": "c3", "name": "기타 1" },
    { "id": "c4", "name": "기타 2" }
  ],
  "items": [
    {
      "id": "d01",
      "name": "십일조",
      "color": "yellow",
      "type": "out",
      "amounts": { "c1": 450000, "c2": 0, "c3": 0, "c4": 0 },
      "memo": ""
    }
  ],
  "updatedAt": "2026-10-11T07:00:00.000Z"
}
```

- 저장할 때마다 커밋 1개가 생성됩니다. 예: `가계부 2026-10 · 십일조 수정 (450,000원)`
- 저장된 파일이 없는 달은 가장 가까운 이전 달(최대 12개월 전)의 항목·열 구성을 가져와 금액 0으로 보여줍니다. 금액을 처음 입력하는 순간 그 달 파일이 생성됩니다.
- 같은 달을 두 기기에서 동시에 저장해 충돌이 나면 최신 파일을 다시 읽어 변경을 적용한 뒤 한 번 재시도합니다.

## 사용법

- 좌우 스와이프 또는 ‹ › 버튼: 이전/다음 달
- 가운데 연월 탭: 이번 달로 이동
- 항목 탭: 열(계좌)별 금액, 메모, 색상, 지출/수입 구분, 순서 이동, 삭제
- 급여 칸 탭: 급여 입력
- 잔액 = 급여 + 수입 항목 − 지출 항목
- 연결 아이콘 → 계좌(열) 이름 변경 (현재 달부터 적용, 다음 새 달에 이어짐)

## 주의

- GitHub 무료 플랜의 Pages는 공개 저장소에서만 동작합니다. **공개 저장소라면 `ledger/data/`의 금액이 누구에게나 공개됩니다.**
- 토큰을 저장한 기기를 다른 사람이 쓰면 저장소를 수정할 수 있습니다. 기기를 분실하면 GitHub에서 토큰을 바로 삭제하세요.
- 삭제하거나 고친 금액도 Git 커밋 기록에는 남습니다.
